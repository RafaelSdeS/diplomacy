# Fase 3 · Crescimento

**Quando:** depois da edição de 2027
**Objetivo:** fazer o app valer a pena de uma edição para a outra e, se houver interesse, abrir para outras simulações.
**Começa quando:** a edição seguinte do UFRGSMUN quer usar o app.

## Escopo

- [ ] Avaliações da mesa e prêmios.
- [ ] Passaporte do delegado: cada simulação vira um carimbo e cada prêmio uma condecoração.
- [ ] Retrospectiva no fim do evento, pronta como story do Instagram.
- [ ] Recortes de jornal: matérias que citam o delegado ficam no passaporte.
- [ ] Outros eventos usando o app: só quando houver interesse real. O modelo de dados já separa eventos, então não precisa reescrever nada.

## Fica de fora até lá

Nenhum recurso é construído só para atender vários eventos antes desta fase.
